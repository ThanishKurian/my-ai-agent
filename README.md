# my-ai-agent

A simple Python project for learning how to build applications with agentic AI, one line of code at a time.

## Overview

This repository currently contains a minimal Python app that prints a greeting to the console.

## App

File: `app.py`

```python
print("Hello world!")
```

## Run it

```bash
python app.py
```

Expected output:

```bash
Hello world!
```
